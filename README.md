# Do India's human and animal antimicrobial resistance surveillance networks speak the same language?

Code and derived outputs for a study by Siddalingaiah H S.

**Status:** in preparation. The analysis plan is released here before any outcome is analysed; that
release carries a Zenodo DOI and serves as the pre-registration. Code and outputs follow in later releases.

## Data

ICMR AMRSN annual reports and the ICAR–FAO INFAAR analytical report 2019–2022 (published documents). Unit-level survey files are not redistributed; obtain them from the original provider.
Only code and aggregate outputs are kept here.

## Layout

| Folder | Content |
|---|---|
| `docs/` | Analysis plan and data notes |
| `src/` | Analysis code |
| `outputs/` | Aggregate results tables (no unit-level data) |
| `tests/` | Checks of the data build and of the results |
